# Sources et crédits

Photographies : sept fichiers fournis par l’utilisateur dans le dossier img du projet initial. Les noms originaux ont servi à identifier les lieux. Les originaux sont préservés. Les fichiers WebP sont des versions redimensionnées, réorientées et compressées. Le site ne revendique pas de licence publique sur les photos.

Correspondance :
- Front_de_mer.JPEG → front-de-mer
- jardin_essai_alger.JPEG → jardin-essai
- monument_martyres.JPEG → monument-martyrs
- Notre_Dame_Afrique.JPEG → notre-dame-afrique
- alger_downtown.JPEG → centre-ville
- alger_nuit.JPEG → alger-nuit
- Rue_place_audin_nuit.JPEG → place-audin

Textes de présentation, logo SVG et montage du diaporama : créés pour ce projet. Les descriptions visuelles se basent sur les photos fournies.
Audio : texte original, voix française de synthèse Denise, générée avec edge-tts. Il ne s’agit pas d’un enregistrement sur place.
Vidéo locale : montage des sept photographies, avec titres ; il ne s’agit pas d’une vidéo filmée sur place.
