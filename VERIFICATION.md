# Vérification du projet

## Contrôles réussis

- 4 pages HTML distinctes, chacune avec un h1.
- Tous les chemins locaux, ancres internes, sources et variantes srcset existent.
- Images avec attribut alt ; champs du formulaire associés aux labels.
- Identifiants uniques dans chaque document.
- Polices, CSS, Bootstrap et JavaScript hébergés localement.
- Fichiers audio et vidéo décodés intégralement avec FFmpeg, sans erreur.
- Justification technique : environ 263 mots.
- JavaScript vérifié séparément avec node --check.

## Limites

Aucun navigateur pilotable disponible dans cette session. Le rendu visuel à 375, 768 et 1280 pixels, le comportement réel des interactions au clavier et la lecture dans le navigateur ne sont pas validés automatiquement. La vidéo externe est référencée par la source officielle UNESCO, mais sa lecture intégrée n’a pas pu être vérifiée. La procédure manuelle figure dans README.md.
